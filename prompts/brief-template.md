# Brief 模板：派给编码子 agent 的任务说明

子 agent 是从零开始的，看不到你和我的对话。**它能看到的只有这份 brief 和仓库。** brief 里没写的东西，对它来说就不存在。

```
## 1. 目标
（一句话：做完以后，什么东西变了）

## 2. 真相来源
（让它先读哪些文件；内容冲突时以哪个为准）

## 3. 约束和非目标
（不许改的文件、不许加的依赖、不许做的事）

## 4. 设计决定
- 我已经定了：……
- 留给你定的：……（每个都要写出你选了什么、为什么）

## 5. 验收
（跑哪条命令、什么结果算完成；没达到时怎么办）

## 6. 汇报格式
（改了哪些文件；每个设计决定和理由；没做的事；不确定的地方）
```

## 写完自查

- [ ] 换一个完全没看过我们对话的人来读，能照着做吗？
- [ ] 有没有一句话能被理解成两种意思？
- [ ] 验收标准能用一条命令检查吗？
- [ ] 有没有写清楚它**不许**做什么？
- [ ] 有没有要求它把每个设计决定说出来，而不是默默替你选掉？
