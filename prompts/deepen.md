# 元提示词：做深，不做大

用法：把整段贴给 AI，填好三个尖括号。第一轮只做分析；你确认后，第二轮再改写。

```
任务：<粘贴原任务>
结果给谁用：<例如：我自己学习 / 交给编码 agent 执行>

我要的是把这件事做深，不是做大。非目标：不增加新功能、新范围、新交付物。

请分两轮。本轮只做分析，不要改写：
1. 以 <具体角色> 的视角，列出他们会做、而我没提到的 3–5 件事，每件说明为什么重要。
2. 他们会从哪些一手材料入手（原始规格、源代码、测试、原始数据、原论文），给出具体路径或链接。不能核查的，标注【推测】。
3. 他们会用的具体方法和工具。每一项写清楚用它来检查什么。
4. 除了你和我之外，有什么能证明结果是对的（测试、独立数据、第三方基准、真实用户）。每一项写清楚怎么取得、通过的标准是什么。
最后列出你不确定、需要我回答的问题。

等我确认以后，下一轮再改写原提示词，把上面四项写成明确的要求。
```

## 第一次使用的教训

第一次使用时，三个占位符都没填就发出去了。AI 只能自己假设任务是什么。好的 AI 会把假设说出来，等你确认；差的 AI 会闷头猜下去。

**发出去之前，先检查尖括号。**
