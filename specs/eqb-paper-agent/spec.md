## Problem

无论是组卷还是导题，先说组卷的场景。老师可能想练一个阅读理解 B 篇的场景。B 篇里面有很多个主题，比如他想练"不同代际之间的关系"这个主题。

没有 AI、没有 Agent 的话，他得去读一下近期的 B 篇，或者总结这些 B 篇，再把它们的主题选出来，然后把相似的手动拼好。

就这几步。最费时间的有：

1. 找到卷子、找到卷子来源。
2. 提取 B 篇的中心。
3. 我觉得最费时间的是整个卷子的排版。要排好版，他们可能想要一篇一面、一篇一面。

现有的网站功能可能是够的，但是不够快，或者说不够准。

## User outcome

可能是分段式的：

1. 老师很简单地说："我想出个 B 篇，关于代际关系，最近的一些新题。"
2. AI 先筛出一部分题，给出每道题的来源和简介。
3. 老师在这里交互：可能说全部都要，也可能只要一部分，挑他喜欢的。
4. 确定以后，Agent 去做主题，做完主题再做排版。
5. 按照老师的要求，渲染好教师版和学生版、有解析的和无解析的。
6. 老师回来就能看到这个卷子。

## User stories

1. 我是一个英语老师，我想组一套阅读理解 B 篇的题目，以便我的学生训练代际相关的话题。
2. 我是一名英语老师，我想组一套非谓语里考被动的真题，以便我的学生练习非谓语的主动和被动。
3. 我是一名英语老师，我想组一套关于旅游的七选五，以便我的学生练一下这个话题。
4. 请求说得含糊的情况：我想要一份卷子。我想要一个题目。

## Scenarios【agent】

| # | 老师原话 | 期望结果 | 验收要点 |
|---|---|---|---|
| 1 | 组 4 篇高三模拟题阅读理解 B 篇的草稿 | 一份草稿卷，4 篇 B 篇 | 正好 4 篇；都是阅读理解；篇位是 B 篇；没有重复的篇目；每篇都有答案 |
| 2 | 组 20 道高考真题非谓语被动的单句语法，直接出 PDF | 一份 PDF，20 道非谓语被动的语法题 | 刚好 20 道单句；都是历年真题；考的都是非谓语的被动；没有重复；每篇都有对应的答案 |
| 3 | 组 5 篇关于旅游的七选五，真题优先，出成草稿卷给我 | 一份草稿卷，5 篇主题是旅游的七选五 | 真题够的情况下，尽可能用真题 |

### 行为规格

- 请求含糊（"难一点的"，比什么难？）：先问老师。
- 题库里凑不够（要 4 篇只找到 3 篇）：告诉老师不够。
- 结果有冲突（老师这次说"中等难度"，可他平时偏好难题）：听这一次的。

### 自主边界【agent】

| 动作 | 决定 | 理由 |
|---|---|---|
| 搜题、看题 | 自己做 | 搜题、看题这种行为还要再问的话，就很啰嗦 |
| 生成一份草稿卷 | 自己做 | |
| 保存为正式试卷 | 先问老师 | 老师可能还要自己调一下、编辑一下 |
| 修改公共题库里的题 | 绝不做 | 公共的不能被改 |
| 导出 PDF | 先问老师 | 老师可能只想保留个电子版，并不想导出 |

### 记忆【agent】

- 要记：年级、偏好题型、常用难度、用过的题。其中**用过的题是最关键的**。
- 不能记：学生的隐私，比如学生的姓名。
